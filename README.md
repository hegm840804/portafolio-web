# 🚀 Portafolio Profesional - Frontend & QA Automation

Sitio web responsivo y moderno desarrollado con React, Tailwind CSS y Vite, respaldado por una suite integral de pruebas automatizadas E2E con Playwright y flujos orquestados con n8n.

## 🛠️ Stack Tecnológico
- **Frontend:** React 18, Tailwind CSS, Vite
- **QA Automation:** Playwright, JavaScript, E2E Testing, Multi-device Emulation
- **Integraciones:** Webhooks, REST APIs, n8n Automation
- **Despliegue:** Vercel / GitHub Actions (CI/CD)

## 🧪 Ejecución de Pruebas
```bash
# Ejecutar pruebas E2E
npx playwright test

# Ver reporte interactivo con capturas
npx playwright show-report
